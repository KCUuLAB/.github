# Segurança

Encontraste uma falha de segurança num repositório do KCUuLab ou num dos sites (lab.gguerreiro232.com, services.gguerreiro232.com)?

**Não abras um aviso público.** Escreve para **kcuulab@proton.me** com:
- onde está a falha (repositório, página ou endereço);
- como se reproduz;
- o impacto que achas que tem.

Respondo em até 7 dias. Peço que não divulgues a falha antes de estar corrigida. Não há programa de recompensas.
