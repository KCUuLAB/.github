# Código de conduta

Os espaços do KCUuLab (avisos, pull requests e discussões) são para falar de tecnologia com respeito.

**Esperamos:** educação, críticas ao trabalho e não às pessoas, paciência com quem está a começar.

**Não aceitamos:** insultos, assédio, discriminação, spam, publicidade não pedida, nem partilhar dados pessoais de outras pessoas.

Quem não cumprir pode ver a mensagem apagada e ser bloqueado. Para reportar uma situação: **kcuulab@proton.me**.
